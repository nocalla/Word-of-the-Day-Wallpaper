# Word of the Day Wallpaper

## Overview
- Gets Dictionary.com's word of the day & definition
- Overlays word & definition over wallpaper in folder
- Saves file
- Sets file as desktop wallpaper

## Compatibility

| Platform | Status |
|----------|--------|
| Windows | Supported (via `SystemParametersInfoW`) |
| Linux (GNOME, Cinnamon, MATE) | Supported (via `gsettings`) |
| macOS | Supported (via `osascript`) |
